## 📌 كيفية ترتيب الأوراق على الحائط (The Visual Wall)

1. **المركز (أمام عينيك مباشرة):**
   * علّق ورقة اليوم **Daily Focus**. هي بوصلتك اليومية لأهم 3 أولويات فقط.
2. **اليمين واليسار (محيط الرؤية):**
   * علّق بطاقات المشاريع **Project Sheets** للمشاريع النشطة جنباً إلى جنب. خانة **NEXT ACTION** بحجمها وخطها البارز ستجعلك ترى الخطوة التالية لكل مشروع بمجرد النظر للحائط.
3. **أعلى اللوحة:**
   * علّق لوحة الأسبوع **Weekly Overview** (بالعرض الأفقي) لمشاهدة خريطة الأسبوع وأهم 3 أهداف أسبوعية والعقبات المعطلة.
4. **بجانب لوحة المفاتيح / الفأرة على المكتب:**
   * ضع ورقة **INBOX** في متناول يدك مع قلم مخصص للتفريغ السريع دون قطع حبل أفكارك.

## ⚙️ طريقة تشغيل النظام (Workflow)

| **نهاية اليوم (5 دقائق)** | اشطب ما أنجزته (إحساس بالتقدم).<br>فرز ورقة INBOX (نقل للمشروع ➔، أُنجزت ✔، أُلغيت ✕).<br>نقل المهام المتبقية المهمة فقط للغد أو لبطاقة المشروع.<br>تحديد أول شيء ستبدأ به غداً. | `Daily Focus`<br>`INBOX` |

## 🖨️ إرشادات الطباعة للحصول على أفضل جودة

1. افتح أي ملف PDF واضغط `Ctrl + P`.
2. تأكد من ضبط مقاس الورق على **A4**.
3. اختر خيار التحجيم: **Fit to printable area** أو **Actual Size (100%)**.
4. التصميم بالكامل أحادي اللون (Monochrome / Grayscale) فائق الوضوح وعالي التباين، ومناسب تماماً لأي طابعة ليزرية أو حبرية منزلية مع استهلاك اقتصادي جداً للحبر.
